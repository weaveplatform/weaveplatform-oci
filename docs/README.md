# weaveplatform-oci documentation

`weaveplatform-oci` is the home of the OCI image approach shared by hostweave,
guestweave-cli-macos and guestweave-cli-windows: the VM artifact specification, the shared
Go module and the reusable publication workflows.

Start with the [research set](research/README.md). It holds the research reports, the
target architecture, the draft artifact contract, the shared-module design, the migration
plan and the decision records.
